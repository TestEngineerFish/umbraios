# Handoff: Umbra iOS 客户端（一期）

## Overview

Umbra 是一个桌面端 AI 代理客户端：用户用自然语言描述目标，Umbra 调用「能力」、操作电脑、跑工作流，把过程和结果沉淀成任务与记录。

本交接包是它的 **iOS 伴侣端一期**设计。iOS 端不是桌面端的完整移植，产品定位是三件事：

1. **随时下指令**（聊天 / 按住说话 / 常用语 / 灵感）
2. **随时看进度并做决定**（任务、提醒、问答卡确认）
3. **随身取用凭据**（密码保险箱 + 系统级密码填充）

配置类的重活（能力管理、工作流编排、工作区增删）在手机上一律**只读**，文案要明确写「去电脑上做」。

## About the Design Files

这个包里的 `.dc.html` / `.html` 文件是**用 HTML 做的设计参考稿**——它们演示的是最终的视觉与交互行为，**不是可以直接搬进产品的生产代码**。

你的任务是：**在目标工程的既有环境里重建这些设计**（SwiftUI / React Native / Flutter 等），用该工程已有的组件、导航栈、状态管理与样式体系。如果目标工程还不存在，请先为一个 iOS 原生 App 选定最合适的技术栈（**推荐 SwiftUI**，因为设计里大量依赖 Face ID、系统密码填充扩展 AutoFill Credential Provider、锁屏通知动作、后台遮盖这些系统能力），然后在那里实现。

不要把 HTML 里的 DOM 结构、CSS 类名、或那套自研的模板运行时（`support.js`）当成架构参考——它只是让原型能在浏览器里跑起来。**唯一需要严格照搬的是：视觉取值、文案、交互行为、状态机。**

## Fidelity

**高保真（hifi）**。颜色、字号、字重、间距、圆角、动效时长都是最终值，全部来自 Umbra 设计系统的 token。请按 token 精确还原，不要目测。文案也是最终文案（中文，见「Voice」一节的硬规则），不要改写。

唯一例外：**图标是近似手绘版**。设计系统里没有官方图标资产，原型里的内联 SVG 是按 Lucide 规范手绘的近似图标。生产环境请直接接入 [Lucide](https://lucide.dev)（或工程既有图标库），保持 `stroke-width` 1.8–2.2、圆头、`viewBox 0 0 24 24` 不变。**没有正式 logo**：所有需要标志的位置用「橙色圆角方块 + 白色首字母 U」的字标，不要自行绘制标志。

- 页面左右边距 16px；卡片内边距 13–14px；分组间距 10–12px

### 阴影

卡片**一律无阴影**，分层靠 1px 描边 + 底色差。阴影只给真正浮起的层：菜单 `0 8px 24px rgba(0,0,0,.13)`，模态 / 浮层 `0 18px 48px rgba(0,0,0,.22)`。

### 动效

克制。`.12s–.15s ease` 的颜色 / 描边过渡；左滑回弹 `.16s cubic-bezier(.2,.8,.3,1)`；弹框推入 / 返回 `.22s` 横向位移。运行中状态用图标匀速旋转（1s linear infinite）。**无弹跳、无缩放、无入场动画。**

原型是一个单页导航栈，路由标识（`route.s`）如下，按 Tab 分组。栈式导航：`go(s, params)` 入栈、`back()` 出栈，Tab 切换 `root(s, tab)` 重置栈。

| 路由 | 名称 | 用户在这里做什么 |
| --- | --- | --- |
| `chat.contacts` | 会话列表 | 挑一个秘书 / 会话进去；看每条会话的最后一句与未读 |

**对话页要点**：

## Interactions & Behavior

- **导航**：栈式 push / pop，返回箭头在左上；弹框多层时新层从右滑入、返回从左滑入，标题左侧出现橙色返回箭头。**每个承接页、每个演示态都必须有出口**——这是硬规则，一期返工过一次。
- **左滑（SwipeActionRow）**：行底露出 88 / 80px 操作块（warning / danger 实底），行本体 `translateX()`，回弹 `.16s cubic-bezier(.2,.8,.3,1)`。
- **长按**：列表行长按出上下文菜单（编辑 / 移动到分组 / 删除）。
- **敏感值**：显示 8 秒后**自动重新遮盖**；复制后 60 秒清剪贴板，并在反馈文案里写明。复制反馈是**行内**「图标转对勾 + 已复制」1.5 秒，不用 toast。
- **TOTP**：1 秒 tick，30 秒换码，倒计时条匀速；数字 24px / 600 / `.14em` 等宽三位一组。
- **破坏性操作**：不占详情页底部，收进右上菜单 / 长按菜单 / 左滑；实心红只出现在确认弹窗的最终动作。
- **表单校验**：服务端地址查格式；分组 / 身份库 / 标签查重名并给具体原因；主密码查强度（StrengthMeter 四档 + 文字标签）。
- **「看起来在动」的东西必须真的有 tick**：录音时长与波形、倒计时、任务进度、自动锁定倒计时。不允许只在渲染时算一次。
- **下拉刷新**只用于「向服务端补拉」（提醒列表），本地数据不给下拉刷新。

## State Management

原型的状态形状（可直接映射成 SwiftUI 的 `@Observable` store / Redux slice）：

- `stack: [{s, ...params}]` —— 导航栈；`tab` —— 当前 Tab
- `theme: 'light' | 'dark'`
- `settings` —— 连接、通知、通用、保险箱（`autoLockMinutes`、`maskOnBackground`、`faceId`）
- `vault` —— `profiles[]`（身份库）、`groups[]`、`records[]`（每条 `{id, type, title, group, blocks[]}`，`blocks` 是有序控件数组）、`trash[]`、`locked`、`unlockedAt`
- `records[].blocks[]` —— `{kind: 'text'|'secret'|'totp'|'url'|'note'|'image', label, value}`，编辑页对它做增删与上下移
- 会话：`threads[]`、`messages[]`（含 `kind: 'text'|'question'|'progress'`）
- 瞬时 UI：`sheet`（底部选择器，支持多层）、`alert`（确认弹窗）、`toast`、`viewer`（图片全屏）、`recording`

数据获取：一期所有数据都是 mock。真实实现里需要服务端接口 —— 会话与消息、任务与步骤、提醒、灵感、设备与能力、工作区、保险箱同步（端到端加密，Secret Key 不出设备）。**保险箱的加解密必须在设备本地做**，服务端只存密文。

## Voice（文案硬规则，请照搬不要改写）

- 语气像一位话不多的同事。直接说结果，不铺垫、不卖萌、不用感叹号。第二人称「你」，产品自称「Umbra」。中文为主，技术名词保留英文原文。**不用 emoji。**
- **具体大于笼统**，永远给数字和对象：`正在写第 2 节 · 已用 1分12秒`，不是「处理中，请稍候…」。
- **按钮**动词 2–4 字：开始执行 / 重试任务 / 停止 / 删除 / 去充值 / 知道了。**禁用**「确定」「提交」；「取消」只用于关闭弹窗，中断任务用「停止」。
- **错误三段式**（缺一不可）：发生了什么 → 为什么 → 现在能做什么，第三段必须是可点按钮。
  例：`第 2 步中断：模型没有响应` / `glm-4v-plus 返回 429，账户余额不足或没有可用资源包。` / `[去充值] [换模型重试] [查看原始返回]`
- **固定词表**（同一概念绝不换词）：任务、能力、工作区、电脑操作、记录、密码保险箱、常用语、灵感、工作流。不要用作业 / 工单、插件 / 技能、项目 / 目录、computer use、历史、密钥库、提示词模板、收藏 / 笔记。
- 中文全角标点；括号内为纯英文时用半角括号；中英文与数字之间留半角空格；引用界面对象用「」。

## Assets

- **没有图片资产**。产品里几乎没有装饰性图像；唯一的真实图像是电脑操作任务的过程截图（运行时数据），等宽等比、圆角 8px、1px 描边、点击放大。**不要用 stock 照片、不要生成插画。**
- **图标**：原型内是手绘的 Lucide 近似线性图标（`fill:none`、`stroke:currentColor`、`stroke-width:1.8–2.2`、圆头、24 viewBox），渲染 12 / 14 / 16 / 24px。生产请接 Lucide 或工程既有图标库。禁止填充图标、彩色 / 渐变图标、emoji 当图标、用 Unicode 符号（✓ ✗ ⚠）代替图标。
- **没有正式 logo**：橙色圆角方块 + 白色「U」字标。

### 建议的实现顺序

1. Token 层（颜色 / 字号 / 间距 / 圆角，含深色模式）+ 基础组件（列表行、卡片、按钮、SegmentedControl、StatusBadge、ProgressBar）
2. 导航骨架（5 个 Tab + 栈式 push/pop + 底部 sheet / alert / toast）
3. 聊天（含 QuestionCard、TaskProgressCard、VoiceHoldOverlay）
4. 任务 + 提醒 + 灵感
5. 密码保险箱全链路（创建 / 解锁 / 记录 / 编辑 / 分组 / 身份库 / 体检 / 回收站）
6. 系统集成：Face ID、AutoFill Credential Provider Extension、锁屏通知动作、后台遮盖

### 自查清单（一期返工过的地方，别再踩）

- [ ] 每个承接页都有出口（返回 / 关闭 / 可再点一次退出的开关）
- [ ] 每个「点了会怎样」的入口都有真实承接页，不是只弹 toast
- [ ] 计时 / 进度 / 波形真的在 tick
- [ ] 录音的 `pointercancel` / 失焦 / 切后台三条兜底都在，监听不泄漏
- [ ] 状态都是图标 + 文字，不只靠颜色
- [ ] 所有点击区 ≥ 44×44
- [ ] 卡片无阴影；橙色一屏不超过三处
- [ ] 空态、错误态都有具体文案（错误必须三段式）
