# Umbra 设计系统

Umbra 是一个桌面端 AI 代理客户端：用户用自然语言描述目标，Umbra 调用「能力」、操作电脑、跑工作流，把过程和结果沉淀成任务与记录。核心模块：聊天、能力、任务、工作区、记录、灵感、密码保险箱、工作流编排、设置。

这套设计系统从桌面客户端的 8 个模块高保真稿里沉淀出来，目的是让移动端、Web 控制台、嵌入式等其它平台复用同一套视觉与语气，不必从截图反推。

## VISUAL FOUNDATIONS

**总体气质**：像原生桌面工具，不像网页。信息密度高、骨架固定、状态即时。暖灰底色（`#F6F5F2`，纸感偏暖）而非纯白或蓝灰，深色模式是暖棕黑（`#1C1A17`）而非冷黑——这是这套 UI 最容易被认出的底色特征。

**颜色**：单一重点色橙 `#E8590C`，跨主题不变，一屏内只出现在三处——主操作按钮、当前选中项（导航项 / 筛选标签 / 开关开启）、进度指示。其余全靠中性暖灰阶分层。左侧导航 `--nav:#15110E` 在两种主题下都是深色。语义色四档（success 墨绿 / warning 琥珀 / danger 砖红 / 中性灰），每档配一个 `-soft` 底色；深色模式下 `-soft` 转半透明、实色提亮。

**排版**：全系统字体，不引入 webfont。七级字号，从页面标题 27px 到字段标签 11px；正文 12.5px / 行高 1.7。字重只用 400 / 560 / 600 / 650。字段标签用 11px + `letter-spacing:.06em` + `--faint` 色。路径、JSON、密钥、快捷键一律等宽字体。

**背景**：纯色，无渐变、无图片、无纹理、无插画。窗口外的桌面底色 `--desk:#DEDBD5`。三级底色差构成层级：`--rail`（列表栏，最亮）> `--card` > `--bg`（主区）。**禁止**蓝紫渐变、彩色光晕、玻璃拟态大面积使用。

**边框与阴影**：分层靠 1px 描边 + 底色差，卡片一律无阴影。阴影只给真正浮起的层：下拉/右键菜单 `0 8px 24px rgba(0,0,0,.13)`，模态 `0 18px 48px rgba(0,0,0,.22)`。

**圆角**：控件 7–8px，卡片/面板/窗口 11–12px，胶囊/状态点/进度条 999px。不用直角，也不用超大圆角。

**Hover / Press / Focus**：次要按钮与可点卡片 hover 时描边转橙 + 文字转 `--orange-text`（不改底色）；主按钮 hover 转 `--orange-deep`；幽灵按钮 hover 加 `--hover` 底。按下态不做缩放。输入框聚焦时描边转橙，需要更强提示时用 `--focus-ring`（3px `--orange-soft` 光环）。

**动效**：克制。只有 `.12s–.15s ease` 的颜色/描边过渡和开关滑块位移。无弹跳、无缩放、无入场动画。运行中状态用图标匀速旋转（`umspin` 1s linear infinite）。

**透明与模糊**：几乎不用。仅深色模式的 `-soft` 底色用 rgba，导航未选中文字用 `rgba(255,255,255,.62)`。不用背景模糊。

**布局**：固定骨架 —— 标题栏 40px（含 macOS 交通灯）+ 深色导航 176px + 列表栏 300–452px（`--rail`）+ 详情主区 `flex:1; min-width:0`。详情面板常驻右侧，不用浮层抽屉。详情内并排双栏用 `flex:1 1 320px; min-width:300px` + `flex-wrap:wrap`。

**图像**：产品里几乎没有装饰性图像。唯一的真实图像是电脑操作任务的过程截图，等宽等比、圆角 8px、1px 描边，点击放大。不使用 stock 照片、不生成插画。

## CONTENT FUNDAMENTALS

**语气**：像一位话不多的同事。直接说结果，不铺垫、不卖萌、不用感叹号。全程第二人称「你」，产品自称「Umbra」。中文为主，技术名词保留英文原文（`glm-4v-plus`、`429`、路径）。不用 emoji。

**具体大于笼统**。永远给数字和对象：

- 进行中：`正在写第 2 节 · 已用 1分12秒`（不是「处理中，请稍候…」）
- 完成：`全部完成 · 耗时 4分08秒`（不是「恭喜！任务已成功完成」）
- 空态：`还没有任务。在聊天里描述目标，Umbra 会自动建任务`（不是「暂无数据」）
- 删除确认：`删除「周报整理」？记录和产出文件都会一起清掉，无法恢复`（不是「您确定要执行此操作吗？」）

**按钮**：动词 2–4 字，说清按下去会发生什么 —— 开始执行 / 重试任务 / 停止 / 删除 / 去充值 / 知道了。**禁用**「确定」「提交」「取消」（「取消」只用于关闭弹窗，中断任务用「停止」）。

**错误三段式**（缺一不可）：发生了什么 → 为什么 → 现在能做什么，第三段必须是可点按钮。
例：`第 2 步中断：模型没有响应` / `glm-4v-plus 返回 429，账户余额不足或没有可用资源包。` / `[去充值] [换模型重试] [查看原始返回]`

**固定词表**（同一概念绝不换词）：任务、能力、工作区、电脑操作、记录、密码保险箱、常用语、灵感、工作流。不要用作业/工单、插件/技能、项目/目录、computer use、历史、密钥库/vault、提示词模板、收藏/笔记、编排/pipeline。

**标点与空格**：中文全角标点；括号内为纯英文时用半角括号；中英文与数字之间留半角空格；引用界面里的对象用「」。

## ICONOGRAPHY

来源里没有图标字体、SVG sprite 或图标包，图标是逐个手写的内联 SVG，风格统一为 **Lucide 式线性描边**：`fill="none"`、`stroke="currentColor"`、`stroke-width:1.8–2.2`、`stroke-linecap/linejoin:round`、`viewBox="0 0 24 24"`。渲染尺寸 12 / 14 / 16 / 24。

- **代用说明（需确认）**：没有拿到官方图标资产，本设计系统内的图标是按同一线性规范手绘的近似版本。生产环境建议直接接入 [Lucide](https://lucide.dev)（默认 stroke-width 2、圆头，与本规范一致），保持描边宽度不变即可。**如果你们有自己的图标库，请提供，我替换掉这些近似图标。**
- 颜色一律 `currentColor`，由父级文字色决定；不做彩色图标、不做双色图标。
- **禁止**：填充图标、彩色/渐变图标、emoji 当图标、用 Unicode 符号（✓ ✗ ⚠）代替图标。
- 状态图标固定映射：运行中=旋转弧、已完成=对勾、需确认=三角感叹、失败=圆叉、排队中=时钟。
- 品牌位置用字标（橙色圆角方块 + 「U」），不要画标志。

## 无障碍与最小尺寸

- 桌面端正文不低于 11px（元信息）/ 12.5px（正文）；移动端正文 14px 起。
- 移动端点击区域不小于 44×44。
- 状态永不只靠颜色表意，必须图标 + 文字。
- 深色模式下 `--orange-text` 提亮到 `#F0A878` 以保证正文对比度；橙色实底上的文字用纯白。

## 使用说明

- 消费方只需引入 `styles.css` 一个文件，全部 token 随之可用。
- 深色模式：在根元素上加 `data-theme="dark"`。
- 组件用 CSS 变量取色，不含任何 CSS-in-JS 或第三方依赖，可直接拷进 React 工程。
- `guidelines/` 与 `components/core/core.card.html` 是纯 HTML 规范卡片，直接引用真实 token 渲染；它们不依赖打包产物，可以单独在浏览器里打开对照。
