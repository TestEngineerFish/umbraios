# 设计规范增补 · iOS（待合入 Umbra 设计系统）

来源：`Umbra iOS.dc.html` 一期原型。以下是桌面端规范里没有、或在 iOS 上取值不同的部分，建议合入 `Umbra 设计规范.dc.html` 与 `umbra-tokens.json`。未经确认前，这些只在 iOS 原型里生效。

## 1. 取值差异（iOS 覆盖桌面端）

| 项 | 桌面端 | iOS | 理由 |
| --- | --- | --- | --- |
| 正文 | 12.5px | 15px | 手持视距近、字体渲染更粗，12.5 在 iPhone 上偏小 |
| 列表行主文 | 12.5px | 16px | — |
| 列表行副文 | 10.5–11px | 13px | — |
| 字段标签 | 11px + .06em | 12px + .06em | 保持字距不变 |
| 卡片圆角 | 11–12px | 14px | iOS 平台观感；控件 10px（桌面 7–8px） |
| 列表行最小高度 | — | 44px（带副文 60px） | Apple 触达底线 |
| 页面左右边距 | — | 16px | — |
| 图标块 | 24px | 24 / 34 / 44 / 48px | 34 = 记录行徽标，44 = 表单/详情头 |

橙色「一屏三处」的规则不变；语义四色不变；`--nav` 在 iOS 上只用于浮层底板（录音面板、toast）。

## 2. 新增组件（原稿里没有命名组件）

1. **StatusBarChip（连接状态行）** —— 分组标题右侧的「状态点 + 一行小字」，替代占一整行的状态卡。
2. **SegmentedControl（分段控件）** —— 已抽成通用组件 `SegmentedControl.dc.html`：`--chip` 底胶囊 + 白色 `--card` 滑块，切换时滑块 `.22s cubic-bezier(.2,.8,.3,1)` 平移动画；props 为 `segs:[{label, count?, active, go}]`，提醒 / 任务两处已复用，凡有子列表切换的页面都用它。
3. **SwipeActionRow（左滑操作行）** —— 已抽成通用组件 `SwipeActionRow.dc.html`：行本体左滑露出 iOS 26 式**浮动胶囊按钮**（44px 高、图标 + 文字、间距 8，warning 琥珀 / danger 砖红 / 中性灰实底），松手按操作区宽度 45% 阈值回弹或吸附，`.22s cubic-bezier(.2,.8,.3,1)`；点操作后自动收回；滑开状态下点行本体只收回、不触发行点击。props 为 `actions:[{label, icon?, kind, act}]`，行内容作为子节点传入。已接入：提醒列表（再等 10 分钟 / 删除）、聊天联系人（设备行移除）、保险箱记录列表（复制密码 / 回收站）；凡可操作的列表都用它，destructive 动作仍要走确认弹窗。
4. **QuestionCard（问答卡）** —— 分页式多题卡：头部 `橙 soft` 底 + 进度 `2 / 4`，选项行选中转 `--orange` 描边 + `--orange-soft` 底，必答未答时提交键置灰并给一行原因。
5. **TaskProgressCard（任务进度卡）** —— 原地更新，状态徽标 + 进度条 + 一句事件；完成/失败转态并给一个动作按钮。
6. **VoiceHoldOverlay（按住说话浮层）** —— `--nav` 底板 + 两个 56px 圆形落区（取消填 `--danger`、转文字填 `--orange`）+ 底部「松开 发送」状态条；波形气泡用 `--orange` + 模态档阴影。
7. **FieldRow（字段行）** —— 保险箱记录详情用：标签 12/560/.06em + 值（敏感值等宽 + 遮罩）+ 44×44 显示/复制图标按钮；复制反馈是行内「图标转对勾 + 已复制」1.5 秒，不用 toast。
8. **StrengthMeter（密码强度）** —— 4px 进度条 + 文字标签（弱 `--danger` / 一般 `--warning` / 强、很强 `--success`），永不只靠颜色。
9. **TotpRow（两步验证码）** —— 24px/600/.14em 等宽数字分组显示 + 匀速倒计时进度条 + 「{n} 秒后刷新」，1 秒 tick，30 秒换码。
10. **ScoreRing（分数环）** —— 44 / 72px 圆环，`--orange` 描边 + `--orange-text` 数字，用于安全体检。
11. **NotificationPreview（锁屏通知）** —— 深色玻璃卡 + 两个动作按钮，仅用于展示 iOS 推送形态。
12. **MaskScreen（后台遮盖）** —— `--bg` 底 + 52px 橙色字标「U」+ 一行说明。

## 3. iOS 特有规则

- 敏感值显示 8 秒后自动重新遮盖；复制后 60 秒清剪贴板，并在反馈文案里写明。
- 破坏性操作不占详情页底部：收进右上菜单 / 长按菜单 / 左滑，实心红只出现在确认弹窗的最终动作。
- 下拉刷新五个根屏**一律做**（2026-08-05 修订）：有服务端的向服务端补拉；纯本机数据（如当前版提醒）也做，重读本机最新数据 —— 「拉一下看看最新」是肌肉记忆，不按数据来源区别对待。
- 录音、倒计时、进度这类「看起来在动」的东西必须真的有 tick，不允许只在渲染时算一次。

### 4.3 新增 iOS 系统形态（演示均可交互）

1. **灵动岛实况（Dynamic Island Live Activity）** —— 任务执行中：胶囊态 = 橙色旋转弧 + 百分比（等宽字）；点按展开 = 字标 + 任务名 + 一句事件 + 40px 进度环。1 秒真 tick。工具栏「灵动岛实况」可开关。
2. **锁屏 Live Activity** —— 锁屏底部深色玻璃卡：旋转弧 + 任务名 + 事件 + 百分比，与灵动岛同一数据源。
3. **主屏小组件** —— 小号（执行中任务：进度环 + 任务名，无任务时显示今天完成数）、中号（今天的提醒 ×3，只读，勾选需进 App）。圆角 34，跟随任务事件刷新。

规则：灵动岛 / 锁屏实况 / 小组件三处显示同一任务时，数据必须同源同 tick，不允许各算各的。橙色「一屏三处」不变——玻璃层的选中态与进度指示计入三处之内。

## 5. 按钮角色规范（弹层与操作类按钮统一取色）

同一角色在所有组件（确认弹窗、操作表、提醒时间面板、左滑胶囊、表单底部按钮）里取色必须一致：

| 角色 | 背景 | 文字 | 字重 | 备注 |
| --- | --- | --- | --- | --- |
| 主操作（保存 / 设置 / 开始执行） | `--orange` 实底 | 白 | 600 | 一屏最多一个，计入橙色「一屏三处」 |
| 次要操作（换个说法 / 再等 10 分钟等实体按钮） | `--card` + `--border-soft` 描边 | `--text` | 560 | — |
| 取消 / 关闭 | 双按钮布局用 `--chip` 底；独立胶囊用玻璃底 | `--text` | 独立胶囊 600，弹窗内 400 | **不用橙色**——取消不是要推销的动作 |
| 破坏性入口（操作表 / 长按菜单里的删除项） | 无底 | `--danger` | 400 | 永远不是最终执行，点了必进确认弹窗 |
| 破坏性最终确认（确认弹窗右键） | 无底 | `--danger` | 600 | — |
| 左滑胶囊 | `--danger` / `--warning` / `--muted` 实底 | 白 | 600 | 实底红只允许出现在左滑胶囊这一处 |
| 置灰 / 不可用 | `--chip` | `--faint` | 600 | 附一行原因文案 |

按下反馈统一：文字键 `opacity .7`，行/分栏键加 `--hover` 底色，`.1s ease`；不做缩放。

## 6. 页面转场（原型近似说明）

原型里已加近似转场：推入页从右侧滑入（.32s cubic-bezier(.32,.72,.32,1)），返回时上一页从左侧 26% 处带透明度滑回；从屏幕左边缘（28px 内）向右拖超过 70px 触发返回。tab 切换不转场，与 iOS 一致。

**给开发的话**：这只是 Web 原型的视觉近似。真实实现请直接用 UINavigationController 的系统 push/pop 转场和 interactivePopGestureRecognizer（交互式边缘返回，可跟手、可中途取消），不要照抄原型的 CSS 动画参数；系统转场自带出场页视差、阴影与打断处理，这些原型没有模拟。
