# Umbra iOS 实现要点（交接给开发/Claude）

原型：`Umbra iOS v2.dc.html`（iPhone 16 Pro · 393×852 · iOS 26 Liquid Glass）。规范细节见 `设计规范增补-iOS.md`（token、取值、按钮角色表都在里面），本文只列实现时容易漏的点。

## 一、必须封装的通用组件（原型里已抽出或已统一，别散着写）

1. **SegmentedControl 分段控件** — 胶囊轨道 + 白色滑块，切换时滑块 .22s cubic-bezier(.2,.8,.3,1) 平移；props: `segs:[{label, count?, active, go}]`。提醒/任务/灵感三处在用。
2. **SwipeActionRow 左滑操作行** — 左滑露出浮动胶囊按钮（44px 高、图标+文字、间距 8；danger 砖红 / warning 琥珀 / 中性灰实底）；果冻动画：胶囊随滑动距离 0.55→1 连续放大（origin 右侧），松手 45% 阈值吸附回弹；判定：横向位移 >9px 且大于纵向才算滑动，不吞点击；滑开时点行本体只收回不触发点击；露出的缝隙是页面底色，不是白色。所有可操作列表统一用它（提醒/联系人/保险箱记录/分组/常用语）。
3. **滚轮选择器（日期/时间统一组件）** — 底部玻璃面板 + scroll-snap 滚轮列（行高 40、居中 chip 高亮）；日期单列「8月5日 周三」，时间双列时/分；「取消/确定」按按钮角色表取色。**禁止用浏览器原生 date/time picker**。点击整个字段区域弹出，不是点图标。真机实现直接用 UIDatePicker(.wheels) 即可。
4. **锚定小弹框（popover）** — 选项少（≤6 项、纯选择）一律从触发控件旁展开 172px+ 玻璃小列表（当前项橙对勾、点空白收起、spring 展开 origin 朝触发点），**不用全宽底部弹层**。底部操作表只用于：需要文字输入、带说明的多动作（换头像等）。
5. **确认弹窗 alert** — 280px 玻璃卡居中，标题 17/600、正文 13 灰，双按钮分栏（取消=正文色，确认=红/橙 600），按下有 --hover 底色反馈。**所有删除/破坏性操作必须走它**，左滑删除也不例外。
6. **下拉刷新** — 五个 tab 根屏统一：顶部玻璃圆盘 spinner，随拉距渐显旋转，46px 阈值触发。
7. **消息长按菜单** — 长按 0.48s（真机用 UILongPressGestureRecognizer），锚定气泡一侧：复制/引用回复/添加提醒/删除（红、走确认）。
8. **toast** — 深色玻璃胶囊 rgba(21,17,14,.72)+blur，底部浮出。

## 二、导航与 chrome（系统层玻璃，内容层不透明）

- 玻璃 token 只给 chrome：导航按钮（38px 圆钮/36px 胶囊）、浮动 tab bar（左右 22 / 离底 26 / 高 64）、浮层。**内容卡片一律不透明**，守 Umbra「几乎不用透明模糊」。
- 大标题 34/700；上滑 14–58px 区间小标题栏连续渐显（不是 0/1 跳变），玻璃背景从屏幕最顶端一直盖到小标题底部（状态栏文字在其上层）；所有推入页同规则。
- 页面转场：真机直接用 UINavigationController push/pop + interactivePopGestureRecognizer，**不要照抄原型 CSS 动画**（原型只是近似：右滑入 .32s，返回左侧 26% 滑回，左缘拖 70px 返回）。tab 切换无转场。
- 提醒/灵感详情是**就地编辑**（同页切换预览/编辑态，导航变「取消/保存」），不推新页。文案统一用「保存」。

## 三、iOS 系统集成（原型里有演示，实现要用真 API）

- **灵动岛 / 锁屏 Live Activity / 主屏小组件**（ActivityKit + WidgetKit）：三处显示同一任务时必须同源同 tick；胶囊态=橙旋转弧+百分比（等宽字），展开态=字标+任务名+事件+进度环；小组件只读、点击深链进对应页。
- 通知：点通知本体进详情，动作按钮就地处理。
- 头像：点头像弹操作表（相册 / 拍照 / 恢复默认），列表与会话顶部同一份数据源。
- 语音：光标不在输入框时长按输入区直接进语音；聊天输入框多行自适应，最大约 5 行后内滚；模式/发送按钮贴底对齐（不居中）。

## 四、细节规则（容易漏）

- 输入框（单行/多行/搜索）圆角统一 12px；胶囊只给按钮、分段控件、tab bar。多行文本框要有 max-height。
- 列表行标题最多 2 行省略，点行进详情看全文；行内勾选圈/箭头上下居中。
- 提醒勾选：先画勾（圈立即变绿），停一拍，再整行淡出收合移除。
- 重复规则子项（频率/间隔/结束日期）：同卡片白底，左缩进 32px、行高 38、标签 15px 灰——不换底色。
- 「间隔（每）」输入框只允许数字，默认 1；「结束重复」默认永不，选指定日期才出现日期行。
- 标签输入框上方列已有标签 chips 供点选（选中橙 soft 底描边）。
- 编辑表单打开必须预填当前值；新建列表项直接插入默认记录并聚焦名称就地改（身份库的做法）。
- 破坏性入口（菜单里的删除项）是红字，但**永远不是最终执行**——必进确认弹窗。
- 空态/错误文案守 Umbra 语气：给数字和对象，错误三段式（发生了什么/为什么/能做什么+按钮）。
- 点击区域 ≥44×44；正文 ≥14px；状态永远图标+文字，不只靠颜色。

## 五、Web 原型 ≠ 真机实现的地方

- backdrop-filter 玻璃 → UIVisualEffectView / .ultraThinMaterial
- CSS scroll-snap 滚轮 → UIDatePicker / UIPickerView
- 长按 setTimeout → UILongPressGestureRecognizer
- 下拉刷新手势 → UIRefreshControl（样式自定义）
- 底色 #F1EFEA / #151310（暖灰，勿用系统默认冷灰）；深色模式 orange-text 提亮 #F0A878；橙实底上文字纯白。
